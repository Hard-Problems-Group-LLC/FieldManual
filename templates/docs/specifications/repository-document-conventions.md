# Repository Document Conventions

Status: Draft

## Purpose

Define how non-knowledgebase working documents are stored, linked, and exposed
in the local viewer.

## Initial Direction

- Use Markdown by default for proposals, bugs, backlog files, working notes,
  and other project-management artifacts.
- Make active repository workflow Markdown browsable in the local viewer.
- Give each browsable Markdown document a unique top-level `#` heading.
- Prefer wiki links for internal links between browsable documents.
