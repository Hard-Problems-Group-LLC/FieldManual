# Upstream Feedback And Engineering Change Intake

The canonical target-neutral ECR standard is now
[Engineering Change Requests](engineering-change-requests.md).

An upstream dependency is one common ECR target, but the same ownership,
identity, lifecycle, transport, intake, and deconfliction rules apply to peer
projects, sibling repositories, services, frameworks, and tools.

This compatibility pointer may be removed after consuming projects update
their links.
