# User-Interface Knacks

Use this area for reusable guidance about interactive presentation, input,
automation, and interface evidence.

- [`terminal/`](terminal/) covers terminal protocols, libraries, rendering,
  keyboard interaction, and text-mode interfaces.
- [`browser/`](browser/) covers browser-driven interaction and test
  automation.

Treat user-interface automation as control of the operations the interface
can reach. Apply the same authorization, isolation, redaction, and evidence
boundaries as a direct API or command-line control path.
