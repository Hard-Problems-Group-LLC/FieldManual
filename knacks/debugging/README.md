# Debugging Knacks

Debugging knacks provide reusable methods for turning an observed symptom
into a tested explanation.

- [High-level debugging](HighLevelDebugging.knack.md) covers evidence
  gathering, hypothesis control, minimal reproduction, instrumentation, and
  verification.

Prefer observations that distinguish competing explanations. Preserve the
original failure until the evidence needed to reproduce and explain it has
been captured.
