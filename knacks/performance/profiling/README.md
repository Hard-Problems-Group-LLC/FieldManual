# Profiling Knacks

- [Web page load and render profiling](WebPageLoadAndRenderProfiling.knack.md)
  covers browser milestones, network and main-thread evidence, repeated
  measurement, and render-readiness interpretation.

Profiles are workload-specific samples. Keep the scenario and capture
conditions with the result, and use multiple evidence sources when a single
timeline cannot separate network, computation, layout, and presentation
costs.
