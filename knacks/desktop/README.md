# Desktop Integration Knacks

These knacks cover development and automation that interacts with a live
desktop or user session rather than an isolated project process.

## Topics

- [GNOME Shell Extension Development](gnome-shell-extension-development.knack.md)
- [Live User-Session Targeting](live-user-session-targeting.knack.md)

Desktop integrations can affect the operator's active session. Read the
[session and project boundaries](../../standards-and-practices/core/session-and-project-boundaries.md)
standard before mutating user-scoped state, and keep version-specific desktop
behavior explicitly tested.
