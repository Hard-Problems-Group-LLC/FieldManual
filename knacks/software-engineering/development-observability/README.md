# Development Observability

Use these knacks when a long-running development session needs a compact,
operator-visible projection of current work without turning transient
telemetry into the project-management source of truth.

## Contents

- [Ubersight Development Observability](ubersight.knack.md)

Development observability may expose work state, repository state, process
metadata, and operator context. Keep each signal within its declared
retention, privacy, and authority boundary.
