# Code-Metrics Knacks

Use these knacks to interpret measurements during design, review, testing, or
refactoring. Do not substitute a metric for reading the code and understanding
its risk.

## Contents

- [Cyclomatic Complexity](cyclomatic-complexity.knack.md)

For reproducible comparisons, record the analyzed scope, tool and version,
configuration, language mode, exclusions, and generated-code policy.
