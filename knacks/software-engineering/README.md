# Software-Engineering Knacks

Use this area for reusable engineering techniques and development-tool
integrations that apply across consuming projects. Language-, framework-, or
platform-specific rules belong in their dedicated standards trees; policy
owned by one consuming project belongs with that project.

## Contents

- [Code Metrics](code-metrics/README.md)
- [Development Observability](development-observability/README.md)

Metrics and heuristics in this tree are prompts for investigation. A
consuming project owns any tool selection, threshold, exception, and
enforcement policy.
