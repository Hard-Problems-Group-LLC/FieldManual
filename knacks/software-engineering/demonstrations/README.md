# Demonstration Knacks

Reviewed: 2026-10-13

Use these knacks when software must be shown to people: scripted tours of a
plugin inside a host application, demonstrations for stakeholders, and
recorded reels. A demonstration shares machinery with automated testing but
answers to a different judge: the person watching.
