# Auditing Knacks

Auditing knacks help build reviewable evidence about software, dependencies,
artifacts, and operating state.

- [Software bills of materials](Software-Bill-of-Materials.knack.md) explains
  SBOM purpose, formats, generation, validation, and lifecycle use.

An audit artifact is evidence with a scope and capture time, not proof that a
system is safe. Preserve the inputs, tool versions, assumptions, and limits
needed to interpret it.
