# Knowledge-Management Project Profile

This optional profile preserves FieldManual's original guidance for
repositories that maintain structured records, narrative pages, uncertain
dates, identity aliases, and wiki-style links.

It is not installed into every consuming project. Load it when the project
actually maintains a knowledge base or comparable data repository.

The profile contains starter specifications rather than universal answers:

- [knowledge-base schema](specifications/knowledgebase-schema.md)
- [repository document conventions](specifications/repository-document-conventions.md)
- [time and uncertainty](specifications/time-and-uncertainty-model.md)
- [wiki-link conventions](specifications/wiki-link-conventions.md)

Projects should copy and complete the applicable specifications in their own
`docs/specifications/` directory.
