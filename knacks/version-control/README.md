# Version-Control Knacks

Use these knacks for bounded Git investigations and recovery work that needs
more operational detail than the
[core version-control standard](../../standards-and-practices/core/version-control-safety.md).

## Contents

- [Purge Large Or Sensitive Files From Git History](purge-large-files-from-git-history.knack.md)

History rewrites are exceptional, externally visible mutations. Analysis and
a decision not to rewrite are valid outcomes. Do not turn these procedures
into unattended cleanup automation.
