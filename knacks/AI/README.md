# AI Knacks

This area contains task-oriented guidance for integrating AI development
products and their local control surfaces. Product behavior changes quickly,
so every product-specific knack must state its source-review date and point to
the current authoritative documentation.

## Topics

- [OpenAI](OpenAI/README.md) — Codex and OpenAI integration guidance

These knacks describe operating boundaries and safe client behavior. They do
not install products, provide credentials, or replace the consuming project's
declared toolchain.
