# AI Knacks

This area contains task-oriented guidance for integrating AI development
products and their local control surfaces, and for orchestrating AI agents.
Product behavior changes quickly, so every product-specific knack must state
its source-review date and point to the current authoritative documentation.

## Topics

- [Agent orchestration](agent-orchestration/README.md) — product-neutral
  patterns for multi-agent development workflows, including staged
  verification
- [OpenAI](OpenAI/README.md) — Codex and OpenAI integration guidance

These knacks describe operating boundaries, safe client behavior, and
workflow patterns. They do not install products, provide credentials, or
replace the consuming project's declared toolchain or verification policy.
