# Field Manual

Lightweight procedures, standards, and workflow guidance for non-coding worker
agents managing structured and unstructured data.

`FieldManual/` is a standalone collection of reusable procedures, standards,
project-management practices, and starter templates for non-coding worker
agents and the humans who supervise them.

It is intended for data-centric work such as:

- creating, organizing, and maintaining structured records
- managing unstructured notes, pages, transcripts, and evidence artifacts
- running lightweight project-management and review workflows around data work
- keeping operational guidance and process state traceable without importing a
  heavy software-development operating system

It is inspired by `TheKnowledge`, but it is intentionally narrower, more
data-oriented, and less tool-heavy.

Working intent:

- keep the parts of `TheKnowledge` that improve traceability and discipline
- adapt the process to knowledge-engineering work, uncertain memories,
  conversational interviewing, and other data-maintenance workflows
- avoid treating general software-development doctrine as the default
- reserve coding-agent or software-engineering rules for repositories that
  explicitly add them elsewhere

Expected contents over time:

- proposal and decision formats
- lightweight project-management conventions
- development-workflow doctrine adapted from TheKnowledge
- interview and ingestion workflow notes
- schema and naming rules for the knowledgebase
- validation rules for link integrity, identity consistency, and temporal data

By default, `FieldManual` is not a general coding handbook. It is meant to help
non-coding worker agents create, organize, and maintain structured and
unstructured data plus the process artifacts surrounding that work.
